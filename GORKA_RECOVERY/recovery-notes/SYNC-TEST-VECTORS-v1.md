1\. PURPOSE AND STATUS

========================================================================



Purpose



This artifact holds the fixed test fixtures and the expected outputs

for the deterministic known-answer test vectors defined in

SYNC-ARCHITECTURE.md v1.1 Section 30.3.



It is the authoritative statement of the byte-level expected

outputs. It is not produced by any implementation under test. Two

implementations that both pass the vectors in this artifact agree

on the bytes.



It is a companion to SYNC-ARCHITECTURE.md. It is not a replacement

for any section of that document. Where this artifact and

SYNC-ARCHITECTURE.md disagree, SYNC-ARCHITECTURE.md wins, and this

artifact is corrected.



Status



PARTIALLY COMPLETE.



This artifact is published in two states of completeness, and the

two are recorded separately per vector:



&#x20; Specification status:

&#x20;   BLOCKED       The vector depends on a protocol parameter that

&#x20;                 has not been frozen in SYNC-ARCHITECTURE.md yet.

&#x20;                 The parameter must be amended into the

&#x20;                 architecture before the expected output can be

&#x20;                 computed.

&#x20;   SPECIFIED     The vector's inputs and operation are fully

&#x20;                 determined by the frozen architecture. Only the

&#x20;                 literal expected output remains to be computed.



&#x20; Expected-bytes status:

&#x20;   PENDING       Cannot be computed until the blocking parameter

&#x20;                 is frozen.

&#x20;   TO BE COMPUTED

&#x20;                 The specification is sufficient; the literal

&#x20;                 expected output has not been generated yet. It

&#x20;                 will be generated by a conforming implementation

&#x20;                 and recorded here, then frozen.



No expected output in this artifact is asserted as authoritative

until it has been computed by a conforming implementation and the

result has been recorded and verified against a second independent

implementation.



What Remains Before This Artifact Is Complete



Three amendments to SYNC-ARCHITECTURE.md are required before the

four BLOCKED vectors can be computed:



&#x20; 1. Section 7.3 must record the exact Argon2id parameters

&#x20;    (memory cost, time cost, parallelism) chosen for the

&#x20;    supported GORKA desktop environment. These are chosen by

&#x20;    benchmarking, not by inventing values for the test artifact.



&#x20; 2. Section 22.19 must contain the exact HKDF domain-separation

&#x20;    label strings. If Section 22.19 does not exist or does not

&#x20;    contain literal strings, it must be added or completed

&#x20;    before H1, H2, and H3 can be computed.



&#x20; 3. E1 has been recorded. H1, H2, and H3 remain to be

&#x20;    computed. When all are recorded, the status changes from

&#x20;    PARTIALLY COMPLETE to COMPLETE.



Vectors M1, M2, V1, V4, and V6 are not blocked by any amendment.

They can be computed as soon as an implementation can run the

specified operations.

5\. WHAT THIS ARTIFACT DOES NOT DO

========================================================================



It does not define architecture. If a vector exposes a gap in

SYNC-ARCHITECTURE.md §30 applies.

specified in SYNC-ARCHITECTURE.md §30.3. This artifact holds only

the deterministic known-answer inputs and outputs.

parameters in §7.3 and the HKDF labels in §22.19 are chosen by

respectively. This artifact records them once they are frozen.

specifies which vectors exist and what they must cover. This

artifact records the fixed inputs and outputs for the

deterministic subset.



It does not constitute an independent security review. It is a

test-fixture and known-answer artifact.
